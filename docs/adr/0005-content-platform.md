# ADR 0005 — Editorial versionado

Status: aceita. Data: 2026-09-26.

Decisão: Markdown no servidor, metadados validados, sem MDX executável ou HTML livre.
Migrar os seis insights preservando parágrafos/datas/slugs. Renderização permite
GFM, matemática e código. Rascunhos nunca chegam a indexação/feed/páginas públicas.
CMS/admin são evolução futura via o mesmo contrato; nenhum banco nesta fase.
